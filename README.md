# Librairie Joon Sh

Application vitrine responsive pour présenter une sélection de livres. Elle ne contient ni panier, ni commande, ni paiement.

## Contenu

- `index.html` : structure complète de la vitrine et coordonnées ;
- `styles.css` : direction artistique responsive ;
- `app.js` : catalogue, filtres, recherche et menu mobile.

## Prévisualisation locale

```bash
cd librairie-joon-sh
python3 -m http.server 8080
```

Puis ouvrir `http://localhost:8080`.
